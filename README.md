# Nevzat Ayaz Anadolu Lisesi Parliament Simulation

![website img](https://i.ibb.co/bgy8wtc2/image.png)

Official website for the Parliament Simulation event organized by Nevzat Ayaz Anadolu Lisesi.

## Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Technologies

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui

## Project Structure

- `/app` - Page routes
- `/components` - React components
- `/lib` - Utility functions and data files
- `/public` - Static assets
